## Abstract
---
Automated real estate valuation is a critical challenge in computational economics, requiring robust pipelines to handle data heterogeneity and non-linear feature relationships. This scientific work demonstrates an end-to-end machine learning framework designed to predict housing prices using Structural and Neighborhood Data, spatial, and structural data points. Leveraging a comprehensive dataset obtained from Kaggle, extensive Exploratory Data Analysis (EDA) was performed. The data preprocessing pipeline integrated advanced feature engineering techniques, including qualitative text cleaning via Regular Expressions (Regex), handling missing values, identifying and mitigating statistical outliers through the Interquartile Range (IQR) methodology, and utilizing One-Hot Encoding for structural alignment of categorical variables.
To systematically evaluate predictive performance, multiple learning paradigms were trained and benchmarked, including Multiple Linear Regression as a baseline, K-Neighbors Regressor, XGBRegressor, and Random Forest Regressor. Performance verification was conducted using rigorous evaluation metrics, specifically R^2 Score and Root Mean Squared Error (RMSE), coupled with cross-validation protocols. The experimental results demonstrated that the ensemble-based Random Forest Regressor outperformed competing models, achieving a superior training R^2 score of 94.05% and a testing R^2 score of 77.58%. The final optimized pipeline was successfully serialized using joblib for scalable deployment. This research highlights the efficacy of integrating robust algorithmic workflows with meticulous data preprocessing to address predictive challenges in complex socio-economic datasets.
